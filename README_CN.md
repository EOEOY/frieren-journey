# 葬送的芙莉莲·旅途

一个以《葬送的芙莉莲》为蓝本的奇幻冒险内容包。**装好就能玩**，非官方同人，版权归原作所有。

## 怎么用（三步）

1. **装包**：设置页 → 插件 → 导入 `frieren-journey-1.3.0.dfplugin`
2. **启用**：在插件列表打开这个包的开关
3. **开玩**：创建游戏时，**规则**和**世界**会自动出现——选「旅途·魔法使与魔族」就能直接开始

## 检定规则

- 只有结果不确定且存在风险的行动才检定；普通交谈、赶路和已具备条件的施法不需要为掷骰而掷骰。
- 检定使用 `d20 + 属性修正 + 技能加值` 对抗 DC；自然 20 为大成功，自然 1 为大失败，DC 最高为 20。
- 优势/劣势掷 2d20 并取高/取低；另一名角色提供有效协助时，本次检定获得优势。
- 旧存档无需转换；更新并启用同一规则 ID 的新版内容包后即可继续游玩。

## 你能玩到什么

### 自动就位（不用动手）
- **规则**：芙莉莲魔法规则——魔法使等级（五级到一级）、魔力、人类魔法解析、魔力制限
- **世界**：旅途·魔法使与魔族，**23 条世界书自动进对局**——魔族、魂眠之地奥列奥尔、北方诸国、库瓦尔山谷、黄金乡、弗拉梅传承、赛丽艾、勇者一行、一级考试、女神之碑……GM 叙事时会按关键词自动浮现

### 可选素材（想要就导入）
以下在「内容包」页面，按需导入到卡库或世界书：
- **角色卡**：芙莉莲、费伦、修塔尔克
- **NPC**：勇者辛美尔、断头台·亚乌拉、僧侣海塔、矮人战士艾泽、大魔族库瓦尔、七崩贤·马哈特
- **职业**：魔法使、战士、僧侣
- **魔法**：弑魔魔法、防御魔法、魔力制限、花田魔法、昏睡魔法、转移魔法、治愈魔法、杀人魔法
- **道具**：镜莲花戒指、魔法书收藏、星夜草、库瓦尔的魔法书残卷

## 玩什么

魔王被讨伐八十年后，精灵魔法使芙莉莲在勇者辛美尔离世后才明白，自己从未真正了解这位共同战斗十年的同伴。她带着弟子费伦与战士修塔尔克，向大陆最北端的「魂眠之地」出发——一路是旅途、回忆，与无法互相理解的魔族。

## 小提示

- GM 可以用「旅途」和「回忆」营造氛围：让角色在赶路时停下来看看风景
- 魔族不理解人类的情感——这是这个世界最核心的张力
- 世界书会按关键词自动浮现设定，GM 不用背设定，顺着线索叙事即可
- 外貌设定已写进角色卡：芙莉莲银白长发翠绿眼眸，费伦黑发蓝绿眼眸，修塔尔克红发——叙事时照此描写，别自行发挥瞳色

## Content V2 与世界书可见性

- 需要 DiceFrame 2.5.0 或更高版本。
- 本版本使用 DiceFrame Content V2：资源 ID 保持 canonical，规则与世界均声明独立 schema。
- 世界书条目显式区分全队可见与 GM 私密；谜底、反转和未发现的异常不会提前显示给玩家。
- 内容包为中文单语言包，`default_locale` 为 `zh-CN`；后续翻译应放入 typed locale overlay，不得修改规则机制。
